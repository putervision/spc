CLI Quickstart

Command Line Usage

# Install Space Proof Code globally via npm npm install -g @putervision/spc # Scan a project directory with default NASA Power of 10 rules spc ./src # Output JSON report file for machine-readable CI/CD integration spc . --format json -o spc-report.json # Fail build if severity threshold or issues are detected spc ./src --max-severity 4 --fail-on-issue
Privacy & Legal Disclaimers

PuterVision LLC Security Guarantee

Data Privacy & Local Execution Guarantee: Space Proof Code (`@putervision/spc`) is engineered by PuterVision LLC with a strict local-first privacy architecture. All static analysis, regex AST parsing, and vulnerability scanning run 100% locally on your machine. No source code, directory structures, or scan results are ever transmitted or collected.

Static Analysis & Safety Disclaimer: While `spc` helps identify critical security anti-patterns (e.g., unchecked return values, unsafe pointer math, recursion hazards, and hardcoded credentials), static analysis cannot guarantee the total absence of runtime defects or mission failures. Developers are advised to complement `spc` with dynamic testing, fuzzing, and formal verification in safety-critical production systems.
