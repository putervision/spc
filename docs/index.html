AI & LLM Security

AI Agent, Skill & MCP Server Auditor

SPC v1.5.0 extends static code analysis to audit your AI agent infrastructure, skills, model context protocol servers, and model deployment configs:

🎯 Skill & Prompt Injection Detection

Flags unescaped user variable interpolation in system prompts, jailbreak patterns, and dangerous shell execution commands like curl | bash inside SKILL.md files.

🛡️ MCP Server Permission Audits

Flags wildcard grants like "command(.*)" or "write_file(.*)" in mcp.json configs, unencrypted env API keys, and unauthenticated public endpoints.

🧠 LLM Model Deserialization Checks

Audits model_config.json and Ollama Modelfiles for unsafe PyTorch weights_only=False flags, HTTP weight downloads, and exposed LLM API keys.

Command Line Usage

# Install Space Proof Code globally via npm npm install -g @putervision/spc # Scan current directory for space-proofing & security issues spc . # Audit AI Agent skills, prompt templates, MCP configs & model files spc . --ai-only --format json -o agent-report.json # Output SARIF report for GitHub Code Scanning integration spc . --format sarif -o spc-results.sarif # Enforce CI quality gate (fail if severity 4+ detected) spc . --max-issue-severity 4 --fail-on-issue
Privacy & Legal Disclaimers

PuterVision Guarantees

Data Privacy & Local Execution Guarantee: Space Proof Code (@putervision/spc) is engineered by PuterVision with a strict local-first privacy architecture. All static analysis, regex parsing, and vulnerability scanning run 100% locally on your machine. No source code, directory structures, or scan results are ever transmitted, telemetry-tracked, or collected.

Static Analysis & Safety Disclaimer: While spc enforces static code rules inspired by NASA's Power of Ten reliability guidelines and AI agent security standards, static analysis cannot guarantee the total absence of runtime defects or mission failures. Developers are advised to complement spc with dynamic testing, fuzzing, and formal verification.
